# Produto — secret.fix

## Licenças

### CORE
Foco em mouse e input.

- Mouse Precision
- Tracking
- Flick Profile
- Sensibilidade
- ajustes de registro seguros para mouse
- seleção de modelo de mouse
- DPI/polling exibidos ou configurados quando suportado
- backup e restore

### PULSE
Tudo do CORE, mais:

- TecladoFix
- Filter/Sticky/Toggle Keys
- Repeat Rate / Keyboard Delay
- FiveM Launcher
- prioridade automática do FiveM
- Auto Boost
- cache manager seguro
- gerenciamento de apps em segundo plano
- perfis salvos

### APEX
Tudo do PULSE, mais:

- Flick/Aim Trainer
- benchmark de input
- Antes × Depois
- Display tuning
- diagnóstico
- múltiplos perfis
- import/export de perfil
- histórico de configurações
- recursos avançados futuros

## Marketing dentro do app

Recursos bloqueados permanecem visíveis com labels como `PULSE+` ou `APEX ONLY`, permitindo upgrade sem instalar outro executável.
