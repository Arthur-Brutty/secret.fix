# Referência visual do secret.fix

Coloque nesta pasta o vídeo de referência visual com o nome exato:

`precisionfix-v3.mp4`

O arquivo é usado apenas como referência de UX/UI para o desenvolvimento do `secret.fix`.

## Instrução para Codex

Antes de alterar o design, o agente deve analisar o vídeo inteiro. Se `ffmpeg`/`ffprobe` estiverem disponíveis, extraia frames distribuídos por toda a duração e compare splash, navegação, MouseFix, TecladoFix, FiveM, Flick, Sensi, Mira, Serviços e Display.

Não reutilize branding, código ou assets proprietários do software de referência. Reproduza apenas a linguagem de layout/UX em uma implementação própria do `secret.fix`.
